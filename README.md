# ספר התנ״ך של סבא רבא — פרויקט משפחתי, כיתה ז׳

אתר שמציג את ספר התנ״ך המשפחתי כספר תלת־ממדי:
- **הספר מבחוץ** — ספר סגור ב־3D שאפשר לסובב בגרירה.
- **לדפדף בספר** — ספר פתוח עם אנימציית דפדוף (חיצים, מקלדת, לחיצה או החלקה).
- **דבר היוצר** — חלון עם דבר היוצר.

## איך מוסיפים תמונות ותוכן
1. שמים את התמונות בתיקייה `images/`.
2. פותחים את `book-config.js` ורושמים את שמות הקבצים (כריכה, שדרה, עמודים).
3. את הטקסט של "דבר היוצר" כותבים באותו קובץ, ב־`creatorNote`.

## איך פותחים את האתר
פותחים את `index.html` בדפדפן.
