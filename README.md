# ספר התנ״ך של סבא שלי — פרויקט משפחתי, כיתה ז׳

🔗 האתר: https://ariellevy2308-design.github.io/FAMILY-PROJECT-7TH-GRADE/

אתר שמציג את ספר התנ״ך המשפחתי כספר תלת־ממדי:
- **הספר מבחוץ** — ספר סגור ב־3D עם תמונות הכריכה האמיתיות (כריכת מתכת), אפשר לסובב בגרירה.
- **לדפדף בספר** — ספר פתוח עם אנימציית דפדוף. כל עמודי התנ״ך נוצרים בקוד בסגנון הספר המקורי
  (נייר ישן, כתמים, מספרי עמודים באותיות). אפשר לדפדף בחיצים, במקלדת, בלחיצה או בהחלקה, ולקפוץ לכל ספר.
- **דבר היוצר** — חלון עם דבר היוצר.

## איך משנים דברים
- תמונות הכריכה ו"דבר היוצר": בקובץ `book-config.js`.
- טקסט התנ״ך: נבנה ע״י `python tools/build_text.py` לתוך התיקייה `data/`.
