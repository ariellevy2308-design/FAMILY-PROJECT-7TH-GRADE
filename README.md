# הסידור של סבא גדעון — פרויקט משפחתי, כיתה ז׳

🔗 האתר: https://ariellevy2308-design.github.io/FAMILY-PROJECT-7TH-GRADE/

אתר שמציג את הסידור המשפחתי — שסבא גדעון קיבל בבר המצווה שלו — כספר תלת־ממדי:
- **הספר מבחוץ** — ספר סגור ב־3D עם תמונות הכריכה האמיתיות (כריכת מתכת עם חלקים בולטים), אפשר לסובב בגרירה.
- **לדפדף בספר** — ספר פתוח עם אנימציית דפדוף. כל עמודי הסידור (נוסח עדות המזרח) נוצרים בקוד בסגנון הסידור המקורי
  (נייר ישן, כתמים, מספרי עמודים באותיות, הוראות באותיות קטנות). אפשר לדפדף בחיצים, במקלדת, בלחיצה או בהחלקה,
  ולקפוץ לכל תפילה.
- **דבר היוצר** — חלון עם דבר היוצר.

## איך משנים דברים
- תמונות הכריכה ו"דבר היוצר": בקובץ `book-config.js`.
- טקסט הסידור: נבנה ע״י `python tools/build_siddur.py` לתוך התיקייה `data/`
  (אחרי בנייה מחדש צריך לשנות את `DATA_VER` ב־`script.js`).
